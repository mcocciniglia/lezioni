Java — Oggetto monitor e synchronized

Esercizio pratico: ottenere un output “a blocchi” senza interleaving tra thread.

Obiettivo

Hai un oggetto A con due metodi m1() e m2(). Due thread partono insieme: uno chiama m1(), l’altro chiama m2().

Devi ottenere un output “a blocchi”:
o termina completamente m1() e poi parte m2(),
oppure il contrario.

Non deve succedere che le righe si mescolino (interleaving), tipo:

[m1] step 1
[m2] step 1
[m1] step 2
...

Cosa fare

  1. Esegui il programma così com’è: vedrai che m1 e m2 si mescolano.
  2. Modifica solo la classe A per ottenere l’output a blocchi.
  3. Regola: se un thread è dentro m1(), nessun altro deve entrare in m2() sullo stesso oggetto A (e viceversa).

Consegna: file MonitorExercise.java + 2-3 righe di spiegazione del perché ora non si mescola.

Codice scheletro (copia/incolla)

Incolla in un file chiamato MonitorExercise.java e avvia da IDE o terminale.

public class MonitorExercise {

    public static void main(String[] args) throws InterruptedException {
        A a = new A();

        Thread t1 = new Thread(() -> a.m1(), "T1");
        Thread t2 = new Thread(() -> a.m2(), "T2");

        t1.start();
        t2.start();

        t1.join();
        t2.join();

        System.out.println("\nFINE PROGRAMMA");
    }

    static class A {

        // TODO (OBIETTIVO):
        // Fai in modo che m1() e m2() NON si intersechino (niente interleaving).
        // Suggerimento: devono usare LO STESSO lucchetto.

        public void m1() {
            System.out.println(">>> m1 START (" + Thread.currentThread().getName() + ")");
            for (int i = 1; i <= 8; i++) {
                System.out.println("[m1] step " + i);
                sleep(120);
            }
            System.out.println("<<< m1 END (" + Thread.currentThread().getName() + ")");
        }

        public void m2() {
            System.out.println(">>> m2 START (" + Thread.currentThread().getName() + ")");
            for (int i = 1; i <= 8; i++) {
                System.out.println("[m2] step " + i);
                sleep(120);
            }
            System.out.println("<<< m2 END (" + Thread.currentThread().getName() + ")");
        }

        private static void sleep(long ms) {
            try {
                Thread.sleep(ms);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }
    }
}

💡 Suggerimento (nascosto)

Clicca “Mostra suggerimento” solo dopo aver provato per 5 minuti.

Se due metodi devono escludersi a vicenda, devono sincronizzarsi sullo stesso monitor. In Java, un metodo synchronized di istanza usa il monitor di this.

Quindi: fai in modo che m1() e m2() “chiedano la stessa chiave”.
