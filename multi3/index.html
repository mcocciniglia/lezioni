Stampante condivisa — slot singolo

Scheletro da completare: monitor con attesa/risveglio

📌 Istruzioni

  • Completa solo le parti TODO.
  • Non usare busy waiting (niente cicli vuoti per aspettare).
  • Il sistema ha uno slot: può contenere al massimo 1 richiesta.
  • Se lo slot è pieno, gli utenti devono attendere.
  • Se lo slot è vuoto, la stampante deve attendere.

🧠 Concetto chiave

synchronized da solo protegge l’accesso (mutua esclusione), ma qui serve anche cooperazione: un thread deve potersi fermare finché la condizione non è vera.

Domanda guida

Quando lo slot è pieno/vuoto: chi aspetta e chi lo risveglia?

Regola importante

Quando si aspetta una condizione, si usa while e non if (perché un thread può essere risvegliato anche se la condizione non è ancora vera).

class UserClient implements Runnable {

    private final String name;
    private final SpoolerMonitor spooler;

    UserClient(String name, SpoolerMonitor spooler) {
        this.name = name;
        this.spooler = spooler;
        new Thread(this, "User-" + name).start();
    }

    @Override
    public void run() {
        try {
            Thread.sleep((int)(Math.random() * 2000));

            int pages = 1 + (int)(Math.random() * 10);
            PrintJob job = new PrintJob(name, pages);

            spooler.submit(job);

            System.out.println(Thread.currentThread().getName()
                    + " -> inviato: " + job
                    + " | slot vuoto? " + spooler.isSlotEmpty());

        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
    }
}

class PrinterDevice implements Runnable {

    private final SpoolerMonitor spooler;

    PrinterDevice(SpoolerMonitor spooler) {
        this.spooler = spooler;
        new Thread(this, "Printer").start();
    }

    @Override
    public void run() {
        try {
            while (true) {
                PrintJob job = spooler.take();

                System.out.println("Printer -> stampa: " + job);

                // tempo stampa proporzionale alle pagine
                Thread.sleep(job.pages * 250L);

                spooler.onPrinted(job);
            }
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
    }
}

public class Laboratorio {
    public static void main(String[] args) {

        SpoolerMonitor spooler = new SpoolerMonitor();

        new PrinterDevice(spooler);

        // più utenti della "capienza" (1) per forzare attese
        new UserClient("Mario", spooler);
        new UserClient("Giulia", spooler);
        new UserClient("Luca", spooler);
        new UserClient("Anna", spooler);
        new UserClient("Paolo", spooler);
    }
}
Vincoli tecnici obbligatori
  • Non usare Thread.sleep() per “gestire” la sincronizzazione.
  • Non usare cicli vuoti tipo while(slot != null){}.
  • Se usi attesa/risveglio, la condizione va in un while, non in un if.
Output atteso (a grandi linee)

Gli invii e le stampe appariranno in ordine variabile. Però non devono mai verificarsi situazioni impossibili: due utenti che “scrivono” nello slot insieme oppure la stampante che stampa quando lo slot è vuoto.
