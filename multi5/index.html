Soluzione — Stampante con slot singolo

Monitor con wait() e notifyAll()

🎯 Obiettivo della soluzione

Realizzare un sistema corretto di produttore / consumatore senza usare code, garantendo:

  • mutua esclusione
  • attesa condizionata
  • assenza di busy waiting

📄 Codice completo

class PrintJob {
    final String user;
    final int pages;

    PrintJob(String user, int pages) {
        this.user = user;
        this.pages = pages;
    }

    @Override
    public String toString() {
        return user + " (" + pages + "p)";
    }
}

class SpoolerMonitor {

    private PrintJob slot = null;
    private long totalPrintedPages = 0;

    // PRODUCER
    public synchronized void submit(PrintJob job) throws InterruptedException {

        while (slot != null) {
            wait(); // slot occupato → attesa
        }

        slot = job;
        notifyAll(); // avvisa la stampante
    }

    // CONSUMER
    public synchronized PrintJob take() throws InterruptedException {

        while (slot == null) {
            wait(); // slot vuoto → attesa
        }

        PrintJob job = slot;
        slot = null;

        notifyAll(); // avvisa gli utenti
        return job;
    }

    // Stato condiviso: va protetto
    public synchronized void onPrinted(PrintJob job) {
        totalPrintedPages += job.pages;
    }

    public synchronized long getTotalPrintedPages() {
        return totalPrintedPages;
    }
}

class UserClient implements Runnable {

    private final String name;
    private final SpoolerMonitor spooler;

    UserClient(String name, SpoolerMonitor spooler) {
        this.name = name;
        this.spooler = spooler;
        new Thread(this, "User-" + name).start();
    }

    @Override
    public void run() {
        try {
            Thread.sleep((int)(Math.random() * 2000));

            int pages = 1 + (int)(Math.random() * 10);
            PrintJob job = new PrintJob(name, pages);

            spooler.submit(job);

            System.out.println(Thread.currentThread().getName()
                    + " -> inviato: " + job);

        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
    }
}

class PrinterDevice implements Runnable {

    private final SpoolerMonitor spooler;

    PrinterDevice(SpoolerMonitor spooler) {
        this.spooler = spooler;
        new Thread(this, "Printer").start();
    }

    @Override
    public void run() {
        try {
            while (true) {
                PrintJob job = spooler.take();

                System.out.println("Printer -> stampa: " + job);

                Thread.sleep(job.pages * 250L);
                spooler.onPrinted(job);
            }
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
    }
}

public class Laboratorio {
    public static void main(String[] args) {

        SpoolerMonitor spooler = new SpoolerMonitor();

        new PrinterDevice(spooler);

        new UserClient("Mario", spooler);
        new UserClient("Giulia", spooler);
        new UserClient("Luca", spooler);
        new UserClient("Anna", spooler);
        new UserClient("Paolo", spooler);
    }
}

🧠 Perché funziona

  • synchronized garantisce la mutua esclusione
  • while gestisce correttamente l’attesa condizionata
  • wait() sospende il thread senza consumare CPU
  • notifyAll() risveglia i thread potenzialmente interessati

⚠️ Errori tipici da evidenziare

  • Usare if invece di while
  • Dimenticare notifyAll()
  • Usare sleep() al posto di wait()
  • Accedere a totalPrintedPages senza sincronizzazione

🔍 Estensioni (facoltative)

  1. Aggiungere una seconda stampante: cosa cambia?
  2. Gestire una terminazione pulita del thread stampante
  3. Riscrivere la soluzione usando Semaphore
