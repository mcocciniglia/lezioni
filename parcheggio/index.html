Semafori in Java

TPSI · Concorrente e sincronizzazione · Esempio guidato: parcheggio con posti limitati

Idea chiave

Un semaforo gestisce un numero di permessi (permits). Ogni thread che vuole usare una risorsa deve:

  • acquire() → prende 1 permesso (se non c’è, attende)
  • release() → restituisce 1 permesso

Se i permessi sono 1 → semaforo “binario” (simile a un mutex). Se i permessi sono N → limita l’accesso a N risorse.

Esempio: parcheggio con 3 posti

Simuliamo 10 auto (thread). Il parcheggio ha solo 3 posti. Quindi al massimo 3 auto possono “stare dentro” contemporaneamente.

Cosa osservare quando lo esegui
  • Quando i posti finiscono, le auto si mettono in attesa su acquire().
  • release() va in finally: anche se succede un errore, il permesso viene restituito.
  • Con new Semaphore(3, true) abilitiamo la fairness (coda più “giusta”).

Codice Java (da copiare in ParkingLotDemo.java)


import java.util.concurrent.Semaphore;
import java.util.concurrent.ThreadLocalRandom;

/**
 * ParkingLotDemo
 * ------------------------------------------------------------
 * Esempio didattico: uso di un semaforo CONTATORE in Java.
 *
 * Scenario:
 * - Ci sono 3 posti auto disponibili.
 * - Arrivano 10 auto (10 thread).
 * - Ogni auto:
 *    1) prova ad entrare (acquire)
 *    2) resta parcheggiata per un tempo casuale (sleep)
 *    3) esce (release)
 *
 * Obiettivo:
 * - Dimostrare che un semaforo con N permessi limita
 *   l'accesso concorrente a una risorsa "con capacità N".
 */
public class ParkingLotDemo {

    // Numero massimo di auto che possono essere nel parcheggio insieme
    private static final int POSTI = 3;

    /**
     * Semaforo con 3 permessi.
     * fairness = true: i thread vengono sbloccati in modo più "equo"
     * (tendenzialmente in ordine di arrivo).
     */
    private static final Semaphore postiLiberi = new Semaphore(POSTI, true);

    public static void main(String[] args) throws InterruptedException {

        // Creiamo 10 thread, ciascuno rappresenta un'auto
        Thread[] auto = new Thread[10];

        for (int i = 0; i < auto.length; i++) {
            int id = i + 1;

            // Runnable "auto": esegue la logica entra-parcheggia-esci
            auto[i] = new Thread(() -> entraParcheggiaEsci(id), "Auto-" + id);

            // Avvia il thread
            auto[i].start();
        }

        // join() serve per aspettare la fine di tutti i thread (opzionale, ma utile)
        for (Thread t : auto) {
            t.join();
        }

        System.out.println("Simulazione conclusa.");
    }

    /**
     * Logica eseguita dal thread "auto".
     * Nota bene: release() è in finally per evitare di "perdere" permessi.
     */
    private static void entraParcheggiaEsci(int id) {
        try {
            System.out.println("Auto " + id + " arriva e cerca posto...");

            // acquire() prende 1 permesso.
            // Se i permessi sono finiti, il thread resta BLOCCATO qui
            // finché qualcuno non chiama release().
            postiLiberi.acquire();

            System.out.println("Auto " + id + " PARCHEGGIA. Posti rimasti: "
                    + postiLiberi.availablePermits());

            // Simuliamo il tempo di sosta
            Thread.sleep(ThreadLocalRandom.current().nextInt(400, 1200));

        } catch (InterruptedException e) {
            // Se il thread viene interrotto, ripristiniamo lo stato di interrupt
            Thread.currentThread().interrupt();

        } finally {
            // release() restituisce 1 permesso.
            // IMPORTANTISSIMO: se non lo facciamo SEMPRE, rischiamo il blocco totale.
            postiLiberi.release();

            System.out.println("Auto " + id + " ESCE. Posti rimasti: "
                    + postiLiberi.availablePermits());
        }
    }
}

Mini-esercizio (per casa / laboratorio)

  1. Modifica POSTI e prova con 1 e con 5.
  2. Prova a mettere false nel costruttore del semaforo e osserva l’ordine di ingresso/uscita.
  3. (Sfida) Cambia la storia: 2 stampanti e 8 studenti che vogliono stampare. Struttura identica: Semaphore(2, true).
Errore tipico

Se dimentichi release() (o lo metti fuori da finally), prima o poi “spariscono” permessi e alcuni thread resteranno bloccati per sempre su acquire().

Come eseguirlo (da terminale)

  • Salva il file come ParkingLotDemo.java
  • Compila: javac ParkingLotDemo.java
  • Esegui: java ParkingLotDemo

Se usate un IDE (Eclipse/IntelliJ/NetBeans), basta creare una classe con lo stesso nome e incollare il codice.
